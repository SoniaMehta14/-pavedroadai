Paved Gate

Apache 2.0 license. Alpha.

A fast ingestion gate that sits in front of AI agents. For each request it asks three questions in one parallel round trip, about intent, risk, and whether sensitive data is present. Then it does one of three things: blocks the request with a policy error, answers it with a deterministic handler without calling a model, or passes it to a frontier agent.

Every decision, allowed or blocked, writes an audit record with the raw scores and a hash of the policy that produced it. Enforcement and the audit trail come from the same code path.

Paved Road playbook

MIT license.

An operating playbook for a 90 day AI engagement, with a reference implementation that shows the architecture working. The playbook sets a measured baseline by day 30, one production workflow with a named internal owner by day 60, and a return on investment attribution with a stated method by day 90. It also includes an AI diligence scorecard.

The reference implementation runs against deliberately messy data from a fictional company and reports its accuracy honestly, including the unflattering numbers.
